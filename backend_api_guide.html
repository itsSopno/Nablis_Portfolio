🚀 Portfolio Backend — API Testing Guide

PowerShell Terminal দিয়ে Backend API Test করার সম্পূর্ণ গাইড

Server: http://localhost:5000
⚙ শুরু করার আগে
✅ Server চালু আছে কিনা নিশ্চিত করুন: Backend folder এ npm run dev চালু রাখুন। Terminal এ "Server is running at port 5000" দেখা যাওয়া উচিত।
⚠️ সব Commands একই Terminal Window তে চালান! Step 1 এ Login করে Token পাওয়ার পর, সেই একই terminal এ বাকি commands চালাতে হবে। নতুন terminal খুললে $token হারিয়ে যাবে।
1 Login করুন — Token নিন
POST http://localhost:5000/api/auth/login

প্রথমে Login করে JWT Token নিতে হবে। এই Token দিয়েই পরবর্তী সব Protected API access করা যাবে।

# PowerShell Terminal এ paste করুন:
$response = Invoke-RestMethod `
    -Uri "http://localhost:5000/api/auth/login" `
    -Method POST `
    -ContentType "application/json" `
    -Body '{"email":"admin@portfolio.com","password":"admin123456"}'

$token = $response.data.token
Write-Host "Token: $token"
✅ সফল হলে Token দেখাবে: eyJhbGciOiJIUzI1NiIsInR5cCI6Ikp...
2 Project যোগ করুন
POST http://localhost:5000/api/projects/project
🔐 Protected Route — Token লাগবে Authorization header এ Bearer Token পাঠাতে হবে।
$body = @{
    title       = "Portfolio Website"
    description = "My personal portfolio built with React and Node.js"
    category    = "fullstack"
    tags        = @("React", "Node.js", "MongoDB")
    liveUrl     = "https://myportfolio.com"
    githubClient= "https://github.com/username/portfolio"
    featured    = $true
    tech        = @(@{name="React";icon="react"}, @{name="Node.js";icon="nodejs"})
    date        = "2024"
} | ConvertTo-Json -Depth 5

Invoke-RestMethod `
    -Uri "http://localhost:5000/api/projects/project" `
    -Method POST `
    -ContentType "application/json" `
    -Headers @{Authorization = "Bearer $token"} `
    -Body $body

5 Contact Message পাঠান (Public)
POST http://localhost:5000/api/contact/contact
✅ Public Route — Token লাগবে না (Visitor পাঠাবে)
$contactBody = @{

    email   = "test@gmail.com"
    subject = "Hello from test"
    message = "This is a test message from PowerShell."
} | ConvertTo-Json

Invoke-RestMethod `
    -Uri "http://localhost:5000/api/contact/contact" `
    -Method POST `
